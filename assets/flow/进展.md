# 进展日志（append，新的放最上面）

> 每个 Agent 干完一棒，在**最上面追加一条**。**顶部那条 = 当前交接棒**，下一棒读它接上。
> 一身三用：可复制（整条喂别的 Agent）、可回看（扫一遍知道每个人干了啥）、能接力（顶部即最新）。
> 收工时这条**既写进文件、也贴在回复里**——用户当场看到 + 能直接复制。
> 决策 → `decisions.md`，坑 → `踩坑记录.md`，内容产物 → `docs/`（这里只给路径）。

**交接怎么走**（Agent 之间没有对话通道，只能靠这一条过河）：

```
A 收工 → 写本文件顶部条 → 整条贴回对话
                              ↓ 用户复制
B 开工 → 读 AGENTS.md + 本文件顶部 → 顺指针读文件 → 先复述再动手
```

**B 的开工咒语**（可直接复制）：

> 读 `AGENTS.md` 和 `flow/进展.md` 顶部那条。然后只回答三件事：① 现在在哪一步 ② 下一步第一个动作是什么 ③ 有哪些未决事项需要我拍板。**先不要动手。**
