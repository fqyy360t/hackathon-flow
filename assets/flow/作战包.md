## 6. 路演脚本骨架

目标不是讲"我们做了什么技术"，是让评委在 <N> 分钟内相信：**这是真实问题、真实效果、真实能继续做**。

| 时间 | 你讲什么 | 屏幕上是什么 |
|---|---|---|
| 0:00–0:30 | 钩子：一个具体的人、一个具体的时刻 | 一个真实场景 |
| 0:30–1:10 | 问题：今天他怎么凑合，为什么不够 | 现状 vs 目标 |
| 1:10–1:35 | 一句话方案 | 一句话 + 三项能力 |
| 1:35–3:20 | **现场 Demo**：真实运行，不是录屏 | 必须真跑 |
| 3:20–4:20 | 技术可信度：一张极简架构图 | 为什么不把关键控制交给风险组件 |
| 4:20–5:10 | 结果：**带基线对照 + 主动报反例** | 对照卡 + 证据截图 |
| 5:10–6:00 | 落地：谁付钱、下一步怎么验证 | 路线图 + 一句话 |

**结尾句**：<一句能被记住的话，不要写"感谢聆听">

### 必备答辩准备（每题一句话答案）

1. 为什么不是最简单的做法？
2. 为什么要用 AI？（不用行不行 —— 必须能答）
3. 出错了怎么办？
4. 为什么是这个市场 / 这个用户？
5. 谁付钱、付多少、付几次？

### 三版稿（现场可能被压缩）

| 版本 | 时长 | 保留 |
|---|---|---|
| 完整 | <N> min | 全部 |
| 压缩 | 2–3 min | 痛点一句 + demo + 一个数字 + 一句愿景 |
| 一句话 | 15 s | 我们让 ___ 的人，不用 ___ 就能 ___ |
