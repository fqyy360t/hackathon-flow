# 发布检查清单（照抄，逐项打勾）

> 规则：**任何一项没过，都不许上场。**
> 分三个时间点检查，不要等到最后一次性做。
> 详规：`references/10-发布与部署.md`

---

## 一、T-3：赛前预埋（全部必须就绪）

### 服务器与域名

- [ ] 云主机已开，`ssh` 能进，`docker ps` 正常
- [ ] 域名已解析（国内主机确认**已备案**，没备案就换海外主机）
- [ ] HTTPS 可访问，浏览器显示小锁
- [ ] `/healthz` 返回 200
- [ ] 部署一个 hello 页面，手机 4G 能打开

### 移动端

- [ ] 安卓 keystore 已生成，**备份到两处**（丢了就不能覆盖安装）
- [ ] `assembleRelease` 成功，产物能装
- [ ] `minSdk` 低于演示机系统版本（单独测一次）
- [ ] 分发通道已建：APK 放对象存储，二维码能扫
- [ ] iOS：有开发者账号 → AdHoc profile + 设备 UDID 已登记；无账号 → **确认用录屏兜底**
- [ ] iOS `Archive` 成功过至少一次

### 演示环境

- [ ] 演示机 ≥ 2 台（1 主 1 备），同型号
- [ ] 演示机已登录、已授权、电满
- [ ] 1080p 和 4K 各投屏试过一次（字能看清、不变形）
- [ ] 手机热点测过全链路（会场 WiFi 不可信）

### 密钥与额度

- [ ] 大模型 / 地图 / 存储 / 推送的 key 全部申请完
- [ ] `.env.example` 齐全，缺 key 时能降级跑 mock
- [ ] **额度测过**：够跑完 24 小时（很多免费额度不够）
- [ ] 仓库里没有 `.env`、没有真实密钥

---

## 二、F 点前：首次真实部署

- [ ] 用**真实代码**（不是 hello）部署成功
- [ ] 演示链路在**演示环境**（公网）跑通一次
- [ ] 关键 API 跨域正常（不是靠 localhost 才通）
- [ ] 数据库已初始化且有种子数据
- [ ] `restart: always` 已配（崩了自动起）
- [ ] 日志能落文件（现场排错靠它）

---

## 三、F 点后：定版与复验

- [ ] 从主干拉 `release` 分支，打 tag `v1.0`
- [ ] 重新部署一次，确认公网可访问
- [ ] 确认线上版本 = final 版本（不是旧构建）
- [ ] 录屏已导出 **mp4**（不是剪映工程文件）
- [ ] 路演 HTML 已用 `file://` 双击打开测过（不依赖 dev server）
- [ ] 路演 HTML 最后一页二维码可扫（demo + 仓库两个）

---

## 四、演示前 1 小时：最终彩排

### 主路径

- [ ] 演示机已装 final 版，跑通一遍完整流程
- [ ] 从"打开 App"开始，不是从已登录页面开始
- [ ] 最慢的一步耗时 < 8 秒（超了就提前预热）
- [ ] 没有人需要在这时候改代码

### 兜底路径

- [ ] 本地备份服务能起（`docker compose up` 一条命令）
- [ ] 断网后能切到 `localhost`（前端有 API_BASE 开关）
- [ ] 大模型挂了能切预生成缓存
- [ ] 录屏能在演示机上播放（拷到手机里，不是电脑里）

### 提交物

- [ ] 提交入口已打开并登录（确认截止时间，取宣传页/日程表/现场通知中**最早**的）
- [ ] 所有链接在**手机上**点了一遍（不是电脑上）
- [ ] 表单必填项全部填完
- [ ] 提交后有截图或回执

---

## 五、现场故障速查

| 症状 | 先查什么 | 怎么切 |
|---|---|---|
| 页面打不开 | 手机 4G 试一次 → 区分是网络还是服务 | 网络问题切热点；服务问题切本地 |
| 接口 502/超时 | `docker ps` 看容器是否活着 | `docker compose restart api` |
| HTTPS 证书告警 | 域名解析是否变了、Caddy 日志 | 临时用 http（若允许）或换 IP 访问 |
| App 装不上 | `minSdk` vs 演示机版本、是否开了"未知来源" | 换备用机 |
| App 闪退 | 是否开了混淆、是否缺权限 | 装 debug 包（提前备好） |
| 大模型超时 | 额度 / 网络 | 切预生成缓存 |
| 投屏变形 | 比例不是 16:9 | 换 1080p 版本页面 |

---

## 六、一句话总结

> **域名比服务器重要，签名比代码重要，录屏比现场重要。**
> 这三样都是"赛前 10 分钟，现场 2 小时"的东西。
