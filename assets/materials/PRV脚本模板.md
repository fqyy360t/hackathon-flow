# PRV 脚本模板（2 分钟 launch 视频 / 30 秒粗糙版）

> 原则：**结果先行**。前 15 秒必须出现"用完之后的那个画面"，不是 logo、不是背景、不是团队介绍。

---

## 2 分钟结构

| 时间 | 内容 | 画面 | 旁白要点 |
|---|---|---|---|
| 0–10s | **结果先行** | 用户拿到结果的那一屏（"已确认：包裹仍在"） | "他刚刚只说了一句话。" |
| 10–30s | 痛点（用对方语言） | 差评截图 / 用户翻事件的手部动作 | "现在要做的，是翻 200 条事件，自己判断。" |
| 30–50s | 现在的做法 + 它为什么不够 | 竞品界面 + 一条差评原文 | 不要贬低竞品，只说"它回答的是另一个问题" |
| 50–80s | **核心机制 1**（做什么 / 怎么做 / 为什么） | 一句话输入 + 圈选 → 结构化任务生成 | "AI 做的不是聊天，是把需求编译成任务。" |
| 80–100s | **核心机制 2**（异常与可信） | 遮挡镜头 → 界面进入 UNKNOWN | "它会说'我不知道'——这是它能被信任的原因。" |
| 100–115s | 复用性（换场景再跑一次） | 第二个场景（宠物 / 门店） | "同一套机制，换目标就能用。" |
| 115–120s | 愿景一句 | 品牌/场景画面 | "从厂商定义功能，到用户定义任务。" |

---

## 30 秒粗糙版（赛前用，不是给人看，是给人问）

```
（手机录屏，不剪辑，带口误没关系）

0–8s   结果画面 + 一句旁白："用户说了一句话，系统给出了这个。"
8–20s  从输入到结果的最短路径（一句话 + 圈选 → 结果）
20–30s 一句定性："现在他原本要翻 N 条事件、自己判断。"
```

拿去问 3 个人，只问一句：**"这像不像你会想要的东西？"**
- 说"像"→ 从他的原话里摘出功能点
- 说"没看懂"→ 结果画面不够直白，改画面不改功能
- 说"我用不上"→ 回去改选题，不要改视频

---

## 拍摄检查清单

- [ ] 前 15 秒没有 logo / 没有背景音乐铺垫 / 没有"大家好"
- [ ] 每一个功能都配一个"变化可见"的动作（动一下 → 界面变）
- [ ] 有 1 处"系统说不知道"（可信度证据）
- [ ] 有 1 处"换场景复用"
- [ ] 字幕：关键结论上屏幕大字
- [ ] 结尾没有"谢谢观看"
- [ ] 时长 ≤ 2:00（超过就是没剪）
