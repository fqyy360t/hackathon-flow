# 预赛材料模板（按官方赛制骨架）

> 用法：复制整份到你的项目文件，把【】逐项填掉。**填不满的写"未验证"，不要写 0、不要留空、不要编。**
> 骨架来自赛制原文：一、预赛信息卡；二、方案成果展示【必须包含】；三、自由展示区【可选·加分项】。

## 一、预赛信息卡

| 项目 | 填写内容 |
|---|---|
| 队名 | 【】 |
| 意向赛道 | 【】 |
| 一句话摘要 | 【一句话教 XX 做事，让 XX 能 XX：关键技术 + 关键体验 + 结果】 |
| 队长信息 | 【姓名 / 联系方式】 |
| 成员介绍 & 分工 | 【每人：背景一句话 + 负责什么 + 交付什么可验收的东西】 |

> 一句话摘要句式：`【做什么】的人，可以【一句话/一次操作】就完成【原本要 N 步的事】，并【拿到什么结果】。`

## 二、方案成果展示【必须包含】

### 1. 赛题理解

- **我们对赛题的理解**：用户真正关心的是【】，而不只是【常见误解】。
- **我们采用的路径**：PATH A【场景/机制创新】+ PATH B【交互/体验重构】（只选你真正做的那条）
- **目标用户**：已安装/计划使用【设备】、需要【具体任务】的用户，包括【A、B、C】。不同场景分别配置【目标/规则/权限】。
- **公开用户需求证据**：调研发现 —— 【用户反复做的高频动作是什么，因为要确认什么状态；同时【误报/漏报/繁琐设置】让他们被迫反复调整】。
  - 来源 1：【平台 + 标题 + 链接 + 日期】
  - 来源 2：…
  - 来源 3：…

> 这一节决定「选题明确度」的前两分：**问题定义准确 + 抓住核心矛盾**。

### 2. 具体方案说明（突出 AI 能力）

**核心功能 1｜【名称】**：做什么【一句话】 / 怎么做【流程】 / 为什么这样做【判据】
- 关键设计：【结构化字段 / 状态机 / 兜底机制】
- 界面或流程图：【1 张】

**核心功能 2｜【名称】**：…
**核心功能 3｜【名称】**：…

> 只写 2–3 个。每个必须能回答"做什么 / 怎么做 / 为什么这样做"——这是「方案清晰度」的原文判据。

**AI 在这里的具体作用**：AI 不是聊天层，而是把【自然语言需求】编译成【可执行、可验证的任务】。
**结构化任务字段**：观察对象 / 关注区域 / 触发条件 / 完成条件 / **UNKNOWN 条件** / 证据要求 / 可调用设备与通知方式。

**3.5 我们希望 24 小时后得到的"结果"**
> 用户侧：用户能用【自然语言】把【一件关心的事】交给【系统】，并在一个页面看到【是否已确认 / 依据是什么 / 哪里仍然不知道】；需要时继续问，而不是重新翻记录。

**3.6 团队的 24 小时具体开发事项**（按人 + 按小时，可验收）

**3.7 24 小时后评委应能亲眼验证的 5 件事**
> ① 现场改需求，方案随之变化（不是赛前写死）
> ② 真实设备是主角（动一下，界面跟着变）
> ③ 系统会说"不知道"（进入 UNKNOWN，而不是编答案）
> ④ 结论可追溯（点开就看到证据）
> ⑤ 机制可复用（换场景再跑一次）

### 4. 方案优势 / 创新点

- **业务范围**：不是只解决【单点场景】，而是提供一套【可被用户定义的能力】。
- **AI 能力创新**：从"AI 识别【内容】"升级为"AI 把【需求】变成【可执行任务】"。
- **核心差异**：从"【事件列表】"升级为"【任务状态 + 有证据的结果】"。
- **交互创新**：从"使用工具"变成"和助手沟通"（用户不需要理解【参数 / 规则 / 配置】）。
- **预计量化价值**：不提前编结果，用 24 小时 Demo 现场验证。目标：【3 步内创建任务 / UNKNOWN 误闭环 0 次 / 每个结论可追溯 / 复用到第 2 个场景】。

> 用一句"不是……而是……"收尾，例如：
> **从厂商定义功能，到用户定义任务；从事件提醒，到结果确认；从工具，到能持续沟通的助手。**

## 三、自由展示区【可选·加分项】

任何能让方案更有说服力、体现团队实力的内容：
- 团队成员过往作品链接（强烈建议）
- 现场可复现的技术验证（日志 / 录屏 / 真机照片）
- 早期用户原话或访谈片段
- 复盘与踩坑记录

## 交付前自检（对着 `assets/materials/评分自检表.md` 打分）

- [ ] 每个数字有来源 + 年份
- [ ] 每个结论有"不能用它证明什么"
- [ ] 核心功能 ≤ 3 个，每个答出"做什么/怎么做/为什么"
- [ ] 有 1 张"评委可当场验证"的清单
- [ ] 表格 ≥ 8 张，无装饰图
- [ ] 第 7 节（谁付钱）与第 8 节（可否复制）没有跳过
