**要求**：

- 至少 5 条，其中至少 3 条来自不同平台。

## 四、证据分级（写进材料时必须标）

| 等级 | 定义 | 能不能当主证据 |
|---|---|---|
| A | 一手原文 + 可核链接 + 有日期 | ✅ |
| B | 官方数据 / 财报 / 权威机构 | ✅（要标年份口径） |
| C | 二手转述 / 媒体报道 | ❌ 只能作旁证 |
| D | 模型生成 / 推测 | ❌ 只能进假设台账 |

**铁律**：材料里每个数字旁边必须写清"它是哪一级"和"不能用它证明什么"。

## 五、常见错误

| 错误 | 后果 |
|---|---|
| 只抓好评 | 没有痛感，方案显得可有可无 |
| 把转述当原文 | 被问"原文在哪"就崩 |
| 差评不聚类直接列 | 看不出频次，选错痛点 |
| 只抓一个平台 | 可能是平台特性，不是真需求 |
