# 赛道评估（S-1 产出物）

> 用法：每个候选赛道打 1–5 分，加权求和。**总分不重要，关键是有没有单项 ≤ 2**——单项过低会吞掉其他优势。
> 判据：选"主办方给独占资源 × 24h 能演出效果 × 你有存量"的交集。

## 三条反模式自检

- [ ] 没有选"最擅长但主办方没资源"的赛道
- [ ] 没有选"最热门"的赛道（除非技术能迁移到冷门场景）
- [ ] 没有选"听起来高级但演不出来"的方向（能想出 10 秒画面）
