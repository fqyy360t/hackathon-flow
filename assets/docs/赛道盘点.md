**自检：**

- [ ] 每个"痛点"后面有出处（年报 / 发布会 / 招聘 JD / 专利 / 招标公告），不是"我觉得"

### 7.4 人员定序检查

- [ ] 队长已定（第 1 天）
- [ ] **核心二人已定**（队长 + 主程，第 3 天内）—— 两人没到位前，五维打分的"存量"项是失效的
- [ ] 其余人按环节数补（开赛前 5 天）—— 不是先凑人再选赛道
- [ ] 人定完的当天，已列**未认领清单**（`flow/未认领.md`）
