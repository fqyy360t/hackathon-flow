### 四类状态（少一类，现场就卡在那类）

| 状态 | 什么情况 | 返回什么 | 界面怎么显示 |
|---|---|---|---|
| **成功** |  |  |  |
| **空结果** | 有范围但零条 | 空列表 + 明确文案 | 不报错、不白屏 |
| **无覆盖** | 该范围根本没采集 | 明确说"无覆盖" | **不能显示成"零事件"** |
| **错误** | 接口/依赖失败 | 错误码 + 可读原因 | 可重试 |

> 「空结果」和「无覆盖」必须区分。把"我没采到"说成"没有发生"，是最容易被评委抓住的一句。
