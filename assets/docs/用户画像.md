# 用户画像

> **一个真实的人一张，不超过一页。** 填不满的格子写 `⬜ 未知`，不许用形容词凑。
> 方法来源：`references/02-选题与调研.md` §二·补。**每张卡的最后一行必须是可被推翻的假设**——没有它，这就只是一段人物设定。

---

## 一、画像卡

### 画像 A：<角色名，例如"光伏安装队队长">

| 字段 | 填什么（判据） | 示例 |
|---|---|---|
| **谁** | 职务 / 角色。**不要写年龄段和收入标签** | 3 人安装队队长，管排期和客户沟通 |
| **场景** | 什么时候、多久一次、多长时间内要完成 | 每个项目开工前 1 天，30 分钟内排出 3 天工序 |
| **现在怎么做** | 工具 + 一共几步 + 卡在第几步 | 微信群里问 + Excel 手排；卡在"客户改时间要重排" |
| **为它付过的成本** | 时间 / 钱 / 出过几次错（**已发生的，不是愿付的**） | 每周 4 小时；买过 1980 元代排产软件；半年 2 次返工 |
| **一句原话** | 带日期和来源，不改写 | "客户一改时间，前面排的全废，得重来一遍"（10-12 电话访谈） |
| **我们赌什么** | 一条假设 + **什么证据能推翻它** | 我们认为他愿为"改时间后 5 分钟重排"付 300 元/月；若 3 个受访者都说"重排就重排，人工便宜"则推翻 |

> 判据：把"谁""场景""现在怎么做"三行念给一个不认识这个行业的人听，他能说出"那确实挺烦"——这卡就立住了。他说"所以呢"——回去重填。

## 二、访谈记录（一次一行，照 `02` §二·补的 12 问走）

| 日期 | 受访者（角色） | 关键原话（不改写） | 信号类型 | 用在哪 |
|---|---|---|---|---|
| | | | 触发事件 / 真实替代 / 切换成本 / 放弃原因 / 付费决策链 | 证据表第 __ 行 |

**五类信号**（其余都是噪音，别记）：

- **触发事件**：什么事件让他开始处理这件事
- **真实替代**：他现在实际用什么凑合
- **切换成本**：换掉现有方案要付出什么
- **放弃原因**：他试过什么、为什么不用了
- **付费决策链**：谁签字、预算从哪出、单价上限

## 三、旅程走查

| 步 | 他现在怎么做 | 会在这一步放弃吗 | 证据（原话 / 数据） |
|---|---|---|---|
| 1 触发 | | 没意识到 = 需求不成立 | |
| 2 找方案 | | **多数产品死在这里** | |
| 3 第一次用 | | 超过 3 步开始掉人 | |
| 4 拿到结果 | | 超过 5 分钟就流失 | |
| 5 复用 | | 没有触发场景 = 一次性玩具 | |

> 结论只写一句：**我们改善的是第 ___ 步，而用户主要死在 ___。** 两句不一致，说明方案打偏了。
