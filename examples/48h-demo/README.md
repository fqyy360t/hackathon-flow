# 示例：一场 48 小时比赛，骨架真的被填了一遍

> **这是一场虚构的比赛。** 赛事叫「2026 城市工业黑客松」，队伍叫 CheckMate，产品和人都不是真的。
> 之所以虚构：真实项目的文件里全是客户名、内网地址和别人的仓库地址，不适合公开。
> 但**每一份文件的格式、判断顺序、数字口径都是真的**——它们是从实际比赛记录里脱敏重写出来的。

**这个目录不是让你抄内容的，是让你看「填成什么样才算填了」。** 空模板谁都看得懂，难的是知道该写到什么颗粒度。

---

## 一分钟：这场比赛长什么样

| 项 | 值 |
|---|---|
| 赛制 | 48 小时 · 线上开发 + 最后 3 小时现场路演 |
| 赛道 | 2 个企业命题（A 设备运维 / B 视觉质检） |
| 队伍 | 4 人（1 产品 + 2 全栈 + 1 算法） |
| 拿到链接 | 2026-10-27 |
| 提交截止 | 2026-11-15 09:00 |
| **算出来的档位** | D=19 天，H=48h → **P=17 天 → M 档** |
| **算出来的 F 点** | 11-15 02:00 → 落在 22:00–06:00 → **前移到 11-14 22:00** |
| 评分表 | 赛前只有维度名，**开赛后 29 小时才给完整细则** |

最后这两行是这个示例的重点：**F 点不是背下来的 7 小时，是算出来再按禁改时段修正的**；**评分表也不是赛前就在手上**。

## 三个读法，按你现在的处境挑一个

**① 「我要开始打了，但不知道第一步干什么」**
从 [`docs/product/赛程卡.md`](docs/product/赛程卡.md) 开始读。它展示的是**三个日期怎么变成一张日程**：算 P、选档、算 F 点、算材料冻结。照这个格式填你自己的赛程，20 分钟。

**② 「我已经在打，但团队信息全散在群聊里」**
读 [`flow/进展.md`](flow/进展.md)。三条交接记录，来自三个不同的人/agent，你试着只看这三条，判断「现在能不能接着干」。读完再读 [`flow/decisions.md`](flow/decisions.md)，看被否决的方案是怎么留下来的；最后读 [`flow/踩坑记录.md`](flow/踩坑记录.md)，看死路为什么必须写"试过没用的"。

**③ 「评分表刚拿到，全队慌了」**
读 [`docs/architecture/评分映射表.md`](docs/architecture/评分映射表.md) 的 §三 和 §四。它展示的是拿到评分表后的 90 分钟做了什么：算出缺口 2 个、冗余 1 个、薄弱 1 个，砍了什么、放弃了什么、谁去通知全队。

**④ 「我不知道自己现在几分，也不知道该补哪」**
读 [`docs/architecture/打分记录.md`](docs/architecture/打分记录.md)。同一场项目打了三次分：**没有卡时只排序（⓪）→ 只有维度名时不出加权（①）→ 卡到手后给区间（②）**。重点看轮次 ① 的"哇时刻 1 分 → 一票否决"，那一次直接决定了后面 8 小时投在哪。

## 这七份文件，各看什么

| 文件 | 一句话 | 什么时候看 |
|---|---|---|
| [赛程卡.md](docs/product/赛程卡.md) | 三个日期 → 算 P → 选档 → 算 F 点 → 算材料冻结 | 刚开始打，20 分钟能照填 |
| [赛道盘点.md](docs/product/赛道盘点.md) | 2 个赛道怎么选掉一个；动机判定；人数从环节数反推 | 还不知道打哪个赛道 |
| [评分映射表.md](docs/architecture/评分映射表.md) | 赛前只有维度名怎么建表；**开赛后 29 小时拿到细则，90 分钟怎么重对齐** | 评分表迟到 / 刚拿到表 |
| [打分记录.md](docs/architecture/打分记录.md) | **同一项目打三次分**：无卡只排序 / 等权不出加权 / 官方卡给区间；含偏差追踪 | 想知道"现在几分、该补哪" |
| [进展.md](flow/进展.md) | 三条交接，三个人 / 三次会话；看「未决事项」怎么写 | 团队信息散在群聊里 |
| [decisions.md](flow/decisions.md) | 拍板与否决；**每条都有"否决的方案 & 原因"** | 想知道下一步为什么不能那么做 |
| [踩坑记录.md](flow/踩坑记录.md) | 两条死路；重点是"试过没用的"那一栏 | 遇到坑，或想知道边界怎么写成数字 |

完整骨架有 30 多个文件，这里只放**最能体现「填成什么样」的七份**。其余的空模板在仓库根的 `assets/` 里。

## 一句话

**看格式，别看结论。** 这里面的判断对这场虚构比赛成立，对你的比赛大概率不成立——但「先算 P 再选档」「F 点落在夜里就前移」「评分表到了先算差集再改东西」这些动作是可迁移的。
